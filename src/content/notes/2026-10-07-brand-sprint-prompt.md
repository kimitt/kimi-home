스레드에서 오셨나요? 반가워요 🙌

브랜드명만 바꿔 복붙하면, AI가 직접 검색해서 **브랜드가 하는 말과 고객이 하는 말의 차이**를 정리해 줘요.
새 브랜드를 맡았을 때 10분 안에 감 잡는 용도예요.

**사용법**
1. 웹 검색되는 AI 열기 (ChatGPT 검색 모드, Claude 등)
2. 아래 프롬프트 복사 후 맨 위 칸만 채우기
3. 결과 나오면 출처 링크 2~3개만 직접 확인하기

써보고 어땠는지 스레드 댓글로 알려주시면, 다음 버전에 반영할게요.

## 프롬프트

```
영문 브랜드명: [예: ANUA]
한글 브랜드명: [예: 아누아]
카테고리: [예: skincare / makeup / haircare]
대표 제품: [모르면 비워두기]
타깃 시장: [미국 / 한국 / 일본 등, 모르면 비워두기]

너는 뷰티 브랜드 리서처야. 위 브랜드를 아래 순서대로 직접 웹 검색해서 조사해줘.
검색은 한 번에 끝내지 말고, 단계마다 지정한 검색어로 각각 따로 검색해.
대표 제품과 타깃 시장이 비어 있으면 검색해서 직접 찾아 채워줘.
아래 검색어의 [영문명], [한글명], [카테고리]는 위에 적은 값으로 바꿔서 검색해.

[1단계. 브랜드가 하는 말]
공식 사이트, 공식 인스타그램, 주요 판매처(아마존, 세포라, 올리브영 등)의 브랜드 소개를 검색해서
- 브랜드가 반복해서 쓰는 키워드와 문구 (원문 그대로)
- 브랜드가 설정한 타깃 고객 (한 문장)
- 브랜드가 고객에게 하는 약속 3가지

[2단계. 고객이 하는 말]
아래 검색어로 각각 검색해줘.
1. site:reddit.com [영문명] [카테고리]
2. [영문명] [카테고리] disappointed review
3. [영문명] [카테고리] dupe alternative
4. [한글명] 화장품 후기
5. [영문명] [대표 제품명] review
6. [영문명] amazon review
정리 방법
- 칭찬, 불만, 사용 상황으로 분류
- 자주 나오는 고객 표현은 번역하지 말고 원문 그대로 인용, 옆에 한국어 뜻
- 제품별로 반응이 크게 갈리는 곳이 있으면 따로 표시

[3단계. 차이 찾기]
1단계와 2단계를 비교해서 아래 표를 만들어줘.
| 구분 | 브랜드가 하는 말 | 고객이 하는 말 |
| 겹치는 점 | | |
| 어긋나는 점 | | |
| 리스크 | | |

[4단계. 한 장 정리]
- 브랜드 한 줄 요약
- 고객이 실제로 쓰는 표현 Top 5
- 의외였던 발견 1개
- 크리에이터에게 시딩한다면 강조할 앵글 1개와 주의할 점 1개

[지켜야 할 규칙]
- 모든 인용과 주장에 출처 링크와 작성 연도를 붙여줘
- 3년 이상 지난 자료는 [오래됨]이라고 표시해줘
- 접근이 막힌 사이트는 건너뛰고 다른 결과를 찾아줘
- 다른 브랜드 이야기가 섞인 결과는 버리고, 버린 이유를 한 줄로 알려줘
- 자료가 부족하면 지어내지 말고 부족하다고 말해줘
- 마지막에 "검색한 것 / 찾지 못한 것"을 짧게 정리해줘
```

## 결과 확인 체크리스트

AI 결과를 그대로 믿지 말고 이 세 가지만 확인하세요. 2~3분이면 충분합니다.

- [ ] 출처 링크 2~3개를 직접 열어서 실제 내용과 맞는지
- [ ] 너무 오래된 자료가 결론에 쓰이지 않았는지
- [ ] 다른 브랜드 리뷰가 섞이지 않았는지

---

## 왜 이렇게 만들었나

AI에게 "OO 브랜드 조사해줘"라고만 하면 검색을 한두 번 하고 첫 결과에서 멈춥니다.
직접 테스트해 보니, 검색어 각도를 지정해 주자 찾아오는 자료의 양과 질이 확연히 달라졌습니다.

| | 그냥 시켰을 때 | 검색어를 지정했을 때 |
|---|---|---|
| 고객 리뷰 | 블로그 1개 수준 | 리뷰 수천 개 집계 사이트까지 확보 |
| 발견 | 뻔한 장단점 | 경쟁 브랜드와의 비교 시각까지 등장 |

## 결과 예시: Glossier

| 구분 | 브랜드가 하는 말 | 고객이 하는 말 |
|---|---|---|
| 겹치는 점 | 꾸미지 않은 자연스러움, 쉬운 뷰티 | 브로우·블러셔는 과하게 할 수가 없어서 데일리용으로 좋다 |
| 어긋나는 점 | Skin First. Makeup Second | 사랑받는 건 메이크업, 스킨케어는 평범하다는 반응 |
| 리스크 | (언급 없음) | 클렌저·립밤·향수 리뉴얼 불만, 깨지기 쉬운 패키지 |

- **브랜드 한 줄 요약**: 피부가 먼저라고 말하지만, 고객은 힘 안 들이는 메이크업 브랜드로 기억한다
- **고객 표현**: "Most natural flush you will get from a blush", "I get compliments all the time", "feels basic"
- **의외였던 발견**: 브랜드 슬로건과 고객이 사랑하는 제품이 정반대 쪽에 있다. 인기 제품 상당수가 기존 K뷰티 제품과 비교되는 글도 있다 [오래됨: 2017년 자료]
- **시딩 앵글**: 철학보다 히어로 제품(브로우, 블러셔)을 "5분 데일리 메이크업" 맥락으로 보낸다
